# Sex-Chromosome Dosage in Japanese Quail

## Project Overview

This project investigates sex-chromosome dosage in the Japanese quail (*Coturnix japonica*) using whole-genome sequencing read depth.

The analysis combines:
- **NCBI** for genome assembly and sequencing metadata
- **Galaxy** for sequencing quality control, read alignment, and coverage analysis
- **R** for chromosome-level read-depth normalization and sex-chromosome dosage inference

### Study Question

Can whole-genome sequencing read depth distinguish the expected sex-chromosome complement of a Japanese quail (*Coturnix japonica*) with a ZZ/ZW sex-determination system?
